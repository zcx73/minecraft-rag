# 操作与界面

## 基础键位（Java 版默认）

- **W A S D**：前后左右移动。**空格**跳跃，**Shift**潜行（不掉下边缘、不触发压力板）。
- **鼠标左键**：长按破坏方块 / 攻击。**鼠标右键**：放置方块 / 使用物品 / 交互（开门、开箱子、给动物喂食）。
- **E**：打开背包（Inventory）。
- **鼠标滚轮 或 1~9**：切换快捷栏的 9 个格子。
- **Q**：丢弃手中物品（丢 1 个）。**Ctrl + Q**：丢一整组。
- **F**：把主手物品换到副手。副手可以举盾牌、拿火把、放食物。
- **F3**：打开调试信息屏，显示坐标、朝向、生物群系、区块信息。**F3 + G** 显示区块边界。
- **F5**：切换视角（第一人称 / 第三人称背后 / 第三人称正面）。
- **F1**：隐藏界面（截图用）。
- **F2**：截图，保存在 `.minecraft/screenshots`。
- **F11**：全屏。
- **双击 W**：奔跑（会消耗饥饿值）。
- **Ctrl**：疾跑；**Shift + 左键**在背包里快速移动整组物品。

## 界面里最重要的几个数字

- **血条**（红色心形）：20 点血 = 10 颗心。掉到 0 就死。半颗心算 1 点。
- **饥饿条**（鸡腿形）：20 点。饿了不能疾跑、不能回血。**饥饿值 ≥ 18 时才会自动回血**。
- **经验条**（绿色）：绿色小圆柱，用来附魔、修理。经验等级数字在下方。
- **护甲条**（胸甲形）：穿着护甲时出现，显示护甲值。

## 坐标与方向

按 F3 后左上角会出现 **XYZ** 三个数字，这是你在世界里最可靠的定位方式：

- **X**：东西方向（东增西减）。
- **Y**：高度。海平面大约在 Y=63，地表常见 Y=64~80，基岩在 Y=-64。
- **Z**：南北方向（南增北减）。
- **Facing**：当前朝向（north/south/east/west）。

新手必学：**在家门口记下坐标**，出门前按 F3 看一眼，迷路时就往这个坐标走。1.16 以后可以用**磁石（Lodestone）+ 指南针**做定点导航，或者干脆用告示牌写坐标。

## 背包与存储

- 背包一共 **36 格**：9 格快捷栏 + 27 格主背包 + 4 格护甲 + 1 格副手（Java 版）。
- **箱子**：可以存 27 格，两个箱子并排放可以合成大箱子（54 格）。
- **末影箱**：物品在全世界所有末影箱之间共享，相当于随身仓库，但取放需要走到箱子前。
- 快捷栏第 1~9 格对应数字键，把最常用的（剑、镐、食物、火把、方块）放在前面。

## 难度设置

游戏内按 **Esc → 选项 → 游戏设置（或"Open to LAN"）** 可以改难度，单人存档也能随时改：

- **和平（Peaceful）**：不刷敌对生物，饥饿值不会耗尽，血量自动回复。新手推荐开局用。
- **简单（Easy）**：怪物伤害低，饥饿值耗尽只掉到半颗心。
- **普通（Normal）**：标准难度，饥饿值耗尽会掉血到死。
- **困难（Hard）**：怪物伤害更高，僵尸会把门砸坏，饥饿耗尽会饿死。

作弊指令（`/gamemode`、`/tp`、`/give`）需要世界创建时**开启作弊**，或用"对局域网开放"时勾选允许作弊。

## 基岩版（手机 / 主机 / Win10 商店版）差异

- 没有 F3 调试屏，坐标需要在"设置 → 游戏 → 显示坐标"里打开。
- 副手只有盾牌、地图等少数物品能用。
- 部分红石元件的行为、刷怪规则与 Java 版不同。看教程时注意区分 Java 版和基岩版。
