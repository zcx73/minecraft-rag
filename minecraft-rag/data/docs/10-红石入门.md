# 红石入门

## 红石是什么

红石是 Minecraft 里的"电"。用红石粉连接元件，就能做出自动门、自动农场、灯光、电梯、甚至计算机。新手不用一开始就学复杂的，先掌握 5 个元件就够了。

## 五个基础元件

### 1. 红石粉（Redstone Dust）
- 挖红石矿石得到（需要铁镐，掉落 4~5 个）。
- 放在地上就是导线，能隔着 15 格传递信号，**每传一格信号强度 -1**。
- 红石粉可以爬墙、上台阶（自动连接）。

### 2. 红石火把（Redstone Torch）
- 1 个红石 + 1 个木棍合成。
- **持续输出信号强度 15**，是最简单的"电源"。
- 放在方块侧面/顶部都行，也可以给方块"充能"。

### 3. 拉杆 / 按钮 / 压力板
- 拉杆：1 个木棍 + 1 个圆石，**开关式**，按下一直保持。
- 石按钮：持续 1 秒信号；木按钮：持续 1.5 秒。
- 压力板：踩上去才通电（物品、生物都能触发）。

### 4. 红石中继器（Repeater）
- 3 个石头 + 2 个红石火把 + 1 个红石。
- 作用：**延长信号**（每次补满 15 格）、**延迟信号**（右键调 1~4 tick）、**单向传输**（只往箭头方向）。
- 这是复杂电路的核心，必学。

### 5. 活塞 / 粘性活塞
- 活塞：3 个木板 + 4 个圆石 + 1 个铁锭。通电时把方块**推出去**。
- 粘性活塞：多一个黏液球，**推出去还能拉回来**。
- 活塞最多推 **12 个方块**（Java 版），推不了黑曜石、基岩、刷怪笼。

## 三个新手小项目

### 自动门（最简单的电路）

1. 在门两侧各放一个**压力板**（或者用拉杆）。
2. 压力板下面接红石粉，红石粉连到门的侧面。
3. 踩上去门就开。原理：压力板给门"充能"。

### 隐藏活塞门

1. 用粘性活塞推一个"墙"方块来挡住通道。
2. 拉杆 → 红石粉 → 中继器 → 活塞。
3. 中继器保证信号足够强、方向正确。

### 自动甘蔗/南瓜农场

1. 活塞对准作物根部，用**观察者（Observer）**检测作物长高。
2. 观察者输出信号 → 红石粉 → 活塞推出 → 作物被推掉变成掉落物。
3. 下面放漏斗 + 箱子收集。

## 必须知道的规则

- **信号强度 15 格后消失**，远了要加中继器。
- **红石火把可以被"熄灭"**：当它附着的方块被充能时，红石火把会短暂熄灭，这叫"红石钟"的基础，也是很多陷阱的原理。
- **方块充能**：红石信号能给实体方块充能，方块再把信号传给相邻的红石粉和元件。这是"隔墙传电"的原理。
- **基岩版和 Java 版的红石行为有差异**（尤其是活塞的"准连接性"、BUD 机制），看教程要区分版本。
- **1.21 的合成器（Crafter）** 是新的红石元件，可以自动合成物品。

## 学习路径建议

1. 先做**自动门**和**红石灯**（红石灯 = 4 个红石 + 1 个萤石）。
2. 再做**活塞推拉**的隐藏门。
3. 然后学**观察者 + 漏斗**做自动农场。
4. 最后再碰"红石计算机"这种硬核内容。

## 常见误区

- **红石粉直接连到活塞侧面不行**：活塞要从"屁股"或者隔一个方块充能。
- **中继器方向搞反**：箭头指向输出方向，装反了信号就断了。
- **以为按钮能一直通电**：按钮是脉冲，要常亮用拉杆。
