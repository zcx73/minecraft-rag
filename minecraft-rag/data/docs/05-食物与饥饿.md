# 食物与饥饿机制

## 饥饿条怎么工作

- 饥饿条是 10 个鸡腿 = **20 点饥饿值**，每个鸡腿 = 2 点。
- 饥饿值 ≥ 18 时，角色会自动**回血**（每个回血周期消耗饥饿值）。
- 饥饿值 = 0 时，**持续掉血**（简单难度掉到半颗心为止，普通/困难会饿死）。
- 饥饿值 < 6（少数情况 < 18）时**不能疾跑**。
- 还有一条隐藏的**饱和度**：吃东西先补饱和度，再补饥饿值。饱和度越高，饥饿值掉得越慢。所以"吃高饱和度食物"比"吃很多低饱和度食物"更耐饿。

## 食物中毒（饥饿效果）

吃生肉、腐肉、河豚、蜘蛛眼等会获得"饥饿"状态效果：饥饿值掉得更快，且不能自然回血。持续几秒到几十秒。喝**牛奶**能立刻清除所有状态效果。

## 农业：最省心的食物来源

### 小麦（面包）

1. 用锄头右键草方块/泥土 → 变成耕地（需要附近有水，4 格内至少一格水）。
2. 手持小麦种子右键耕地播种。种子来自打草（杂草有几率掉）。
3. 等它长到金黄色（可以撒骨粉催熟，骨粉来自骨头）。
4. 收割得到小麦 + 种子，3 个小麦 → 1 个面包。

### 胡萝卜 / 马铃薯

- 村庄的农田里能直接拔。胡萝卜种下去会长出更多胡萝卜，还能做成金胡萝卜。
- 马铃薯烤一下变成烤马铃薯，是很好的主食。

### 动物养殖

- 用**小麦**吸引并繁殖牛、羊；用**胡萝卜/马铃薯/甜菜根**繁殖猪；用**种子**繁殖鸡。
- 喂两只同类动物 → 生小动物。杀掉成年动物就能拿到肉。
- 鸡会下蛋，鸡蛋能砸出小鸡。

## 前期最实用的三条建议

1. **第一天就打 2~3 只动物**，把生肉烤熟带在身上。
2. **种一小片小麦**，10 分钟后就有稳定面包来源。
3. **下矿前吃高饱和度食物**（金胡萝卜、熟牛肉），别带一堆面包占格子。

## 药水与食物相关的效果

- **牛奶**：清除所有状态效果（包括中毒、饥饿、凋零）。
- **金苹果**：短时间伤害吸收 + 生命恢复，打 Boss 前吃一个。
- **蜂蜜瓶**：恢复饥饿值，还能解除中毒。
- **迷之炖菜**：不同花合成有不同效果，比如"抗性提升"或"夜视"。

## 常见误区

- **一直吃腐肉**：会持续食物中毒，回不了血，得不偿失。
- **以为饥饿条满了就无敌**：满饥饿只是能回血，被苦力怕炸还是死。
- **在下界不吃东西**：下界没法种地，进下界前一定要带够食物。
