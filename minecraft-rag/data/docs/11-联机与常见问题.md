# 联机 / 指令 / 常见问题

## 和朋友一起玩

### 局域网联机（最简单）

1. 一方在游戏里按 **Esc → 对局域网开放（Open to LAN）**。
2. 勾选"允许作弊"（需要指令时）。
3. 记住屏幕上显示的端口（比如 25565 之后随机）。
4. 同一局域网的朋友在"多人游戏 → 直接连接"里输入 `主机IP:端口`。主机 IP 用 `ipconfig` 查（IPv4 地址）。

### 服务器

- Java 版可以下载 **Paper / Fabric / Forge** 服务端搭建。需要 Java 环境、端口转发（外网访问）。
- 基岩版用官方 Dedicated Server，或用 Realms 订阅。
- 新手不折腾服务器：用 **Realms**（官方付费）或局域网就够。

## 常用指令（需开启作弊）

| 指令 | 作用 |
|---|---|
| `/gamemode creative` | 切创造模式（`survival`/`adventure`/`spectator`） |
| `/tp x y z` | 传送到坐标 |
| `/give @s diamond 64` | 给自己 64 个钻石 |
| `/time set day` | 设为白天（`night`/`noon`/`midnight`） |
| `/weather clear` | 晴天（`rain`/`thunder`） |
| `/locate structure village` | 定位最近的村庄 |
| `/seed` | 查看世界种子 |
| `/effect give @s speed 60 2` | 给自己加速 60 秒 2 级 |
| `/enchant @s sharpness 5` | 给手持物品附魔 |
| `/kill @e[type=zombie]` | 杀掉所有僵尸 |
| `/gamerule keepInventory true` | **死亡不掉落物品**（新手强烈推荐） |
| `/difficulty peaceful` | 切和平难度 |
| `/spawnpoint` | 设置重生点 |
| `/setworldspawn` | 设置世界出生点 |

`@s` 是自己，`@p` 是最近玩家，`@a` 是所有玩家，`@e` 是所有实体。

## 种子（Seed）

- 种子决定世界的地形。同一个种子 + 同一个版本 = 同一个世界。
- 查看：`/seed`（需要作弊），或者创建世界时输入的种子。
- 用法：在网上找"村庄在出生点旁边"的种子，输入就能直接生成。
- **注意版本**：1.18 大幅改了地形生成，老种子在新版本里地形会变。

## 死亡与物品找回

- 死亡后物品掉在死亡地点，**5 分钟**内可以捡回，超时消失。
- 掉进岩浆、虚空 = 物品永久丢失（下界合金装备除外，它不会烧毁）。
- 强烈建议开局就输 `/gamerule keepInventory true`，尤其带新手朋友玩的时候。

## 常见问题

**Q：为什么我挖铁矿什么也没掉？**
A：镐子等级不够。铁矿需要**石镐**及以上，木镐挖了只给经验。

**Q：为什么床放不下/睡不了？**
A：床要放在实体方块上，上方留 2 格空间。提示"周围有怪物在游荡"说明附近有敌对生物，先清怪。下界和末地不能用床（会爆炸）。

**Q：怎么快速找到钻石？**
A：挖到 **Y=-58**，用鱼骨挖矿法水平掘进。带"时运 III"的镐能翻倍。

**Q：为什么我做的门怪物能打开？**
A：僵尸在困难难度会砸门。用铁门（需要按钮/拉杆）或者门口挖坑。

**Q：怎么去末地？**
A：需要 12 个末影之眼激活要塞的传送门。末影之眼 = 末影珍珠 + 烈焰粉。

**Q：游戏很卡怎么办？**
A：Java 版按 F3 看帧率；降低渲染距离（选项 → 视频设置 → 渲染距离 8~12）、关闭光影、给游戏多分配内存（启动器里调 -Xmx4G）。基岩版可以降低渲染距离和分辨率。

**Q：存档在哪？**
A：Java 版 `%appdata%\.minecraft\saves`；基岩版 `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\minecraftWorlds`。**备份存档就是复制这个文件夹**。

**Q：Java 版和基岩版能一起玩吗？**
A：不能直接联机。需要跨平台服务端（如 GeyserMC）做桥接。

**Q：为什么我的村民不补货？**
A：村民每天最多补货 2 次，而且必须待在它的职业方块旁边。睡觉也能加速补货。

## 新手最值得改的三个设置

1. **`/gamerule keepInventory true`**：死亡不掉落。
2. **难度调成"简单"**：先熟悉机制，别被怪劝退。
3. **打开"自动跳跃"**（基岩版）或调低鼠标灵敏度，操作会舒服很多。
