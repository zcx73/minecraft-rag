# 合成与工具

## 合成的两种尺寸

- **2×2 合成**：打开背包（E 键）右上角那 4 格，只能做最基础的东西：木板、木棍、工作台、火把、箱子。
- **3×3 合成**：必须放下**工作台**再用右键打开。绝大多数配方都要求 3×3。

新手最常见的卡点：手里有材料却做不出东西，多半是因为没放工作台。

## 从原木到木板

1 个原木 → 4 个木板（木板是独立种类，橡木、云杉木、白桦木不能互相替代配方位置的颜色，但功能一样）。
2 个木板竖着放 → 4 个木棍。木棍是工具、火把、箭的核心材料。

## 木→石→铁→钻石：工具升级路线

| 等级 | 需要的材料 | 能挖的方块 | 说明 |
|---|---|---|---|
| 木 | 木板 + 木棍 | 石头、煤、木头 | 只够撑过第一天 |
| 石 | 圆石 + 木棍 | 铁矿石、青金石 | 性价比最高，坏了不心疼 |
| 铁 | 铁锭 + 木棍 | 金矿石、钻石、红石、绿宝石 | 挖矿主力 |
| 钻石 | 钻石 + 木棍 | 黑曜石、远古残骸（下界） | 长期使用 |
| 下界合金 | 下界合金锭 | 全部 | 不会烧毁、属性最高 |

**只有特定等级以上的镐子才能挖出对应的矿石**：木镐挖铁矿只掉经验不掉矿，石镐挖钻石同样白费。**镐子等级是新手最容易忽略的机制。**

## 常用工具与用途

- **镐（Pickaxe）**：挖石头和矿石。挖得慢，是消耗最快的工具。
- **斧（Axe）**：砍木头快，也能当武器（伤害比剑低一点但破盾强）。
- **锹（Shovel）**：挖土、沙、沙砾。
- **锄（Hoe）**：翻地种田，还能把树叶变成"耕地"？不能，只对泥土/草方块有效。
- **剑（Sword）**：打怪、打动物。攻击伤害最高，攻击速度也快。
- **剪刀（Shears）**：剪羊毛、剪树叶、给羊剪毛不杀羊。
- **打火石（Flint and Steel）**：点燃火、激活下界传送门。
- **桶（Bucket）**：装水、装岩浆、给牛挤奶（空桶右键牛）。
- **钓鱼竿**：钓鱼能拿到食物，还有小概率钓到附魔书、命名牌等宝物。

## 熔炉：把矿石变成锭

熔炉需要 8 个圆石合成。用法：上面放要烧的东西，下面放燃料（木头、木炭、煤炭、岩浆桶都可以），右边出成品。

- 铁矿石 → 铁锭（必须烧，不能直接用）
- 金矿石 → 金锭
- 生肉 → 熟肉（熟肉食物值和饱和度都更高，还不会食物中毒）
- 沙子 → 玻璃
- 圆石 → 石头（再烧一次 → 平滑石头）
- 原木 → 木炭（没煤的时候用它做火把）

**熔炉 → 高炉**：3 个铁锭 + 1 个熔炉 + 5 个平滑石头（1.14+ 配方为 5 铁锭 + 1 熔炉 + 3 平滑石头）能做出高炉，烧矿石的速度是普通熔炉的两倍，但只能烧矿石类。

## 箱子与存储

- 箱子：8 个木板，围成一圈，中间空。27 格存储。
- 两个箱子左右并排放置 → 大箱子 54 格。
- 箱子上方放方块会打不开（1.13 后只有猫坐在箱子上才会挡）。
- **末影箱**（8 个黑曜石 + 1 个末影之眼）：所有末影箱共享同一份 27 格内容，等于随身仓库。

## 第一周的合成优先级

1. 工作台 → 木镐 → 石镐 + 石剑 + 石斧
2. 熔炉（烧铁、烧食物）
3. 箱子（存东西）
4. 火把若干（煤炭/木炭 + 木棍）
5. 床（3 羊毛 + 3 木板）
6. 铁镐（挖钻石的必要条件）
7. 水桶（保命神器：掉进岩浆前泼水能救你一命，也能灭火）
