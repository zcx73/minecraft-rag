# 村庄与村民交易

## 怎么找村庄

- 平原、沙漠、热带草原、针叶林、雪原最容易生成村庄，沙漠和雪原的房子外观不同但功能一样。
- 最快的方法：**沿一个方向直线跑，跑到地图加载出新的区块**。或者站高处看有没有屋顶。
- 找一个**制图师**村民，可以用绿宝石换"林地探险家地图""海洋探险家地图"，直接定位特殊结构。
- 指令 `/locate structure village`（需要开作弊）能直接给出最近的村庄坐标。

## 村民的职业与交易

村民有 15 种职业，由**它旁边的职业方块**决定。给村民一个职业方块，它就会转职；拆掉方块它会变成无业游民。

| 职业 | 职业方块 | 能换什么（举例） |
|---|---|---|
| 农民 | 堆肥桶 | 小麦、面包、南瓜派、苹果 |
| 图书管理员 | 讲台 | **附魔书**、书架、玻璃、指南针 |
| 盔甲匠 | 高炉 | 铁/钻石盔甲 |
| 武器匠 | 砂轮 | 剑、斧、附魔武器 |
| 工具匠 | 锻造台 | 镐、锹、斧 |
| 制箭师 | 制箭台 | 箭、弓、燧石 |
| 牧师 | 酿造台 | 红石、青金石、附魔之瓶、末影珍珠 |
| 皮匠 | 炼药锅 | 皮革、鞍、皮革盔甲 |
| 石匠 | 切石机 | 石英、石砖、陶瓦 |
| 牧羊人 | 织布机 | 羊毛、地毯、画 |
| 渔夫 | 木桶 | 鱼、水桶 |
| 制图师 | 制图台 | 地图、探险家地图 |
| 傻子 | 无 | 什么都换不了，纯摆设 |

**新手最该刷的是图书管理员**：附魔书（经验修补、保护、锋利）只能用绿宝石换，比附魔台赌运气稳定得多。

## 交易的核心规则

- 货币是**绿宝石**。获取方式：卖东西给村民、挖绿宝石矿（仅山地）、和流浪商人换、掠夺者掉落。
- 第一次交易后，村民会"锁定"职业，并开始**涨经验**：铜 → 铁 → 金 → 钻石 → 绿宝石徽章。等级越高，解锁的交易越好、价格越低。
- **反复交易同一个物品会让价格下降**（有下限）；攻击村民会涨价。
- 每个村民只有 **2~4 个交易槽**，等级提升后解锁新槽位。
- 交易界面里，村民会"补货"：每天（游戏日）最多补 2 次，卖完要等。

## 村民的保护与利用

- **铁傀儡**：村庄里天然生成，会攻击僵尸和玩家（如果你打了村民或傀儡）。4 个铁块 + 1 个南瓜可以自己造一个。
- **不要在有村民的地方放床给怪物用**，僵尸会攻击村民，村民被杀就没人交易了。
- **用围墙把村子围起来**，插火把，防止夜晚刷怪。
- **村民会"繁殖"**：给两个村民各 3 个面包（或 12 个胡萝卜/甜菜根/马铃薯），它们会生出小村民。人口多了才能刷出铁傀儡。

## 袭击（Raid）

- 打死**掠夺者队长**（头上带旗帜的那个）会获得"不祥之兆"效果。
- 带着这个效果进入村庄 → 触发**袭击**：一波波掠夺者来打村子。
- 撑过全部波次（简单 3 波、普通 5 波、困难 7 波）→ 获得"村庄英雄"效果，村民交易打折。
- 新手建议：先有铁甲 + 盾牌 + 铁剑再去打袭击，或者干脆躲进地下。

## 给新手的务实建议

1. 找到一个村庄后，**先别急着交易**，把村子周围用栅栏围起来、插满火把。
2. 找到一个讲台，把村民变成**图书管理员**，刷到"经验修补"附魔书就值回票价。
3. 用农民换面包（1 绿宝石 = 6 面包），食物问题直接解决。
4. 缺铁：找盔甲匠/武器匠/工具匠，用绿宝石换铁锭。
5. 流浪商人牵着两只羊驼，东西贵但偶尔有稀有物品（比如珊瑚、海绵）。
