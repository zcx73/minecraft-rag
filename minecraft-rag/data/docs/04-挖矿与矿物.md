# 挖矿与矿物分布

## 先记住版本差异（很重要）

- **Java 版 1.18 及以后**：世界高度范围变成 Y=-64 ~ Y=320，矿物分布大改。网上老教程（1.17 之前）的"钻石在 Y=12"已经过时。
- **基岩版 1.18+** 与 Java 版分布基本一致。
- 下面的数据默认按 **1.18+ Java 版** 说明。

## 各矿物的最佳高度

| 矿物 | 出现范围 | 最密集的高度 | 需要的镐 |
|---|---|---|---|
| 煤炭 | Y=0 ~ 320 | Y=96 附近（山地裸露） | 木镐 |
| 铁 | Y=-64 ~ 320 | Y=16 附近，以及 Y=232 高山 | 石镐 |
| 铜 | Y=-16 ~ 112 | Y=48 附近 | 石镐 |
| 青金石 | Y=-64 ~ 64 | Y=0 附近 | 石镐 |
| 红石 | Y=-64 ~ 16 | Y=-58 附近 | 铁镐 |
| 钻石 | Y=-64 ~ 16 | **Y=-58 附近最密集** | 铁镐 |
| 绿宝石 | 仅山地生物群系 | Y=100 以上 | 铁镐 |
| 金 | Y=-64 ~ 32（恶地地表也有） | Y=-16 附近 | 铁镐 |
| 下界石英 | 下界任意高度 | 下界 Y=10~117 | 木镐 |
| 远古残骸 | 下界 Y=8 ~ 22 | **Y=15 附近** | 钻石镐 |

结论：**想挖钻石，把主矿道挖到 Y=-58，然后在这一层水平掘进**，效率最高。

## 三种主流挖矿法

1. **阶梯矿道（新手首选）**：从家附近往下挖台阶，每格往下走一格，一直挖到 Y=-58。安全、不迷路、随时能爬回去。
2. **鱼骨挖矿（效率最高）**：先挖一条主巷道，然后每隔 2~3 格向两侧挖支巷道。间隔 2 格能保证不漏掉任何矿脉。
3. **洞穴探索（收益最高也最危险）**：直接钻进天然洞穴系统。矿石裸露多、还能顺手捡箱子，但怪物密集、容易掉进岩浆。

## 挖矿安全守则

- **永远不要垂直往下挖**（"1×1 直井"）。下面是岩浆湖你就直接没了。要么挖 2×1 的阶梯，要么站在两格宽的坑里交替挖。
- **随身带水桶**：掉进岩浆前右键泼水，水会变成黑曜石把你托住。这是最实用的保命技巧。
- **随身带 64 个方块**（圆石/泥土），用来垫脚、封路、堵岩浆。
- **带够火把**：1.18+ 的洞穴非常黑，敌对生物在**光照等级 0** 就会生成，比以前的"亮度 7"更容易刷怪。
- **听到水声/岩浆声就小心**，先把脚下的方块探一探再走。
- **不要在矿道尽头背对黑暗**：骷髅的箭能从 16 格外射过来。

## 钻石怎么用最划算

钻石很稀有，前几颗别乱花：

1. **铁镐 + 3 颗钻石 → 钻石镐**（挖黑曜石、远古残骸的前提）。
2. **钻石剑**（伤害 7，是原版最高档的近战武器之一）。
3. **附魔台**（2 钻石 + 4 黑曜石 + 1 书）。如果想先附魔，优先级高于钻石剑。
4. 剩下的留着做钻石盔甲。

## 下界合金（毕业装备）

1. 去**下界**，在 Y=8~22 挖**远古残骸**（看起来像带孔的棕色方块，烧不掉，必须用钻石镐）。
2. 4 个远古残骸 + 4 个金锭 → 1 个**下界合金锭**（在高炉里烧，1.20 起需要下界合金升级锻造模板）。
3. 在**锻造台**上，用下界合金锭 + 模板把钻石装备升级成下界合金装备。
4. 下界合金装备**掉进岩浆不会烧毁**，这是它最大的价值。

## 挖矿装备清单

- 铁镐 2 把（或钻石镐 1 把 + 铁镐 1 把备用）
- 铁剑、盾牌
- 火把 64 个、圆石 128 个
- 水桶 1 个、食物 8 个以上
- 工作台、熔炉（可以现场摆）
- 床（可选，用来在矿洞里设重生点，但在下界和末地不能用）
